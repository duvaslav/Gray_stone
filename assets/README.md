# Графические и звуковые ассеты

Структура соответствует `asset_id` из листов `29_Арт_ассеты_редакция_1` и `31_Использование_ассетов_редакция_1`.

```text
assets/
├── backgrounds/     # фоны локаций и их состояния
├── characters/      # портреты персонажей по эмоциям
├── cg/              # сюжетные CG
├── items/           # предметы и документы
├── poi/             # крупные планы точек поиска
├── ui/              # интерфейс
├── fx/              # атмосферные оверлеи
├── audio/           # музыка, окружение и SFX
└── marketing/       # обложки и промоматериалы
```

Правила именования:

- фон: `assets/backgrounds/<location_id>/<state>.webp`;
- портрет: `assets/characters/<character_id>/<emotion>.png`;
- CG: `assets/cg/<group>/<scene>.webp`;
- предмет: `assets/items/<item_id>.png`;
- точка поиска: `assets/poi/<poi_id>.webp`.

Существующие `backgrounds/library/day.png` и `night.png` сохраняются как временные исходники. При финальной оптимизации допускается WebP-копия, но исходные файлы не удаляются без проверки ссылок.

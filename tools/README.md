# Инструменты

Здесь размещаются скрипты экспорта Google Sheets в JSON и проверки проекта.

Планируемые команды:

- `export-sheets` — выгрузка листов `_редакция_1`;
- `validate-ids` — проверка ссылок между персонажами, сценами, уликами и ассетами;
- `validate-routes` — проверка достижимости событий и концовок;
- `build-asset-manifest` — формирование манифеста файлов из `asset_id`;
- `optimize-assets` — создание WebP и уменьшенных копий без удаления исходников.

Секреты и токены не должны попадать в репозиторий.

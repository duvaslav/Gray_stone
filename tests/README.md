# Проверки

Минимальный набор QA для реализации редакции 1:

- 18 успешных маршрутов: 6 виновниц × 3 стратегии;
- 4 отрицательных маршрута;
- отсутствие softlock;
- обязательное событие выполняется не более одного раза;
- ОД не уходят ниже нуля;
- каждый `asset_id`, `location_id`, `item_id`, `clue_id`, `scene_id` и `event_id` существует;
- финальный resolver всегда формирует `final_result`;
- сохранение загружается только при совместимой версии схемы.

Автоматические тесты будут добавляться рядом с соответствующими валидаторами.

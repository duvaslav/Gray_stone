# Игровые данные

Эта папка содержит машиночитаемую копию канона из Google Sheets, листы с суффиксом `_редакция_1`.

Планируемые файлы:

- `characters.json` — персонажи, стартовые отношения, визуальные ID;
- `locations.json` — локации, вложенные зоны и переходы;
- `schedules.json` — расписания NPC;
- `items.json` — предметы и документы;
- `clues.json` — улики и доказательные категории;
- `events.json` — события, триггеры, эффекты и fallback;
- `dialogues.json` — сцены, узлы, выборы и визуальные переключения;
- `endings.json` — правила четырёхслойного финала;
- `assets.manifest.json` — соответствие `asset_id` реальным файлам.

## Правила

1. ID из таблицы не переименовываются вручную.
2. В коде не дублируется сюжетная логика, которая может храниться в данных.
3. Условия сначала импортируются как структурированные выражения, затем проверяются валидатором.
4. Неизвестный ID считается ошибкой сборки.
5. Диалоги могут обновляться независимо от игрового движка.
